Markdown 是一种很简单的文本标记语言。

平时写博客、写笔记、整理文档的时候，我经常会用到它。刚开始接触的时候语法看起来有点多，其实常用的并不复杂。

这里记录一些最基础的 Markdown 语法，方便以后自己查阅。

---

## 标题

Markdown 使用 `#` 来表示标题。

`#` 越少，标题级别越高。

```markdown
# 这是一级标题

## 这是二级标题

### 这是三级标题
```

显示效果：

## 这是一级标题

## 这是二级标题

### 这是三级标题

> **注意：** `#` 后面建议加一个空格，这是比较规范的写法。

---

## 换行与段落

Markdown 中直接按回车，就可以开始新的段落。

例如：

```markdown
这是第一段。

这是第二段。
```

如果只是想在同一个段落中换行，也可以直接回车。

一般不需要为了换行在行末添加两个空格。

---

## 加粗与强调

想让文字变粗，可以使用两个 `*` 把文字包起来：

```markdown
**这是一段加粗的文字**
```

显示效果：

**这是一段加粗的文字**

也可以使用两个下划线：

```markdown
__这也是加粗文字__
```

不过平时使用 `**文字**` 就已经足够了。

---

## 斜体

使用一个 `*` 可以让文字变成斜体：

```markdown
*这是一段斜体文字*
```

显示效果：

_这是一段斜体文字_

---

## 引用

在文字前面加 `>`，就可以创建引用。

```markdown
> 这是一段引用文字
```

显示效果：

> 这是一段引用文字

引用也可以连续使用多行：

```markdown
> 第一行引用
>
> 第二行引用
```

---

## 列表

## 无序列表

在文字前面使用 `-`：

```markdown
- 游戏开发
- 像素画
- AI
```

显示效果：

- 游戏开发
    
- 像素画
    
- AI
    

## 有序列表

使用数字加 `.`：

```markdown
1. 学习 Markdown
2. 写一篇文章
3. 发布到博客
```

显示效果：

1. 学习 Markdown
    
2. 写一篇文章
    
3. 发布到博客
    

---

## 链接

Markdown 可以很方便地添加链接：

```markdown
[GitHub](https://github.com/)
```

显示效果：

[GitHub](https://github.com/)

基本格式就是：

```text
[显示的文字](链接地址)
```

---

## 图片

图片的写法和链接很像，只需要在前面加一个 `!`：

```markdown
![图片说明](图片地址)
```

例如：

```markdown
![一张图片](https://example.com/image.png)
```

---

## 代码

如果只是文章中的一个代码或命令，可以使用反引号：

```markdown
使用 `git push` 上传代码。
```
