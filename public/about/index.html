你好，我是 Redou，一个写代码、也写字的人。

这个站点叫「屿光」——取其安静：像水上的一座小岛，天黑之后还有一点光。它没有评论区，没有阅读量，也没有算法推荐，只是一间放在网上的书房。

我在做什么

白天写程序，主要和前端、静态站点、构建工具打交道；晚上读点书，偶尔把手边的想法整理成文章。我偏爱那些能用很久的东西：一把键盘、一支钢笔、一个十年还在维护的软件。

关注的几件事

  • 简单：能用一个文件解决的问题，不引入一个框架。
  • 可读：无论是代码还是文章，第一读者都是半年后的自己。
  • 手写：笔记、清单、日程，尽量落到纯文本上，而不是某个应用的云端。

技能与工具

  • 语言：JavaScript / TypeScript、Go（够用）、Shell
  • 前端：React、Vue、原生 CSS，偏好不加构建步骤的小项目
  • 静态站点：Hugo、Markdown、Git
  • 编辑器：VS Code 与 Neovim 轮换使用，配置文件都放在仓库里
