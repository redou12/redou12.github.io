站点升级说明 v2.0：从 PaperMod 迁移到 Stack

换主题、拆配置、搬家内容的一次完整记录：哪些变了，哪些特意没变。

2026年9月24日星期四 阅读时长: 3 分钟

这个博客从建立到现在，一直用的是 PaperMod 主题。它足够简单，也足够稳，但我用了两年之后，慢慢觉得首页的排布不太适合我这种"一篇篇慢慢写"的节奏——文章列表偏紧凑，图片也不太好放。

于是这次花了一个晚上，把站点从 PaperMod 迁移到了 Stack，顺便把配置和内容结构一起理了一遍。更新时间：2026 年 9 月 24 日。

换了什么

项目 v1.0（PaperMod） v2.0（Stack）
主题 PaperMod Stack v4.0.3
配置文件 单个 hugo.yaml config/_default/ 下四个文件
内容结构 单文件 文章.md 一篇文章一个目录（page bundle）
文章封面 无 每篇一张本地生成的渐变色封面
导航 顶部横向导航栏 左侧侧栏 + 社交图标
站内搜索 有 有（构建时生成索引）
评论 无 无（配置位置已留好）

配置拆成四个文件之后，改东西终于不用在一百多行 yaml 里翻了：

  • hugo.toml：站点地址、语言、分页、固定链接、Markdown 渲染
  • params.toml：侧栏、文章行为、小部件、评论
  • languages.toml：语言与站点描述
  • menu.toml：社交图标
📝 备注

主题换掉不影响内容。Stack 同样基于 Hugo，文章还是 Markdown 文件，没有引入任何数据库或后台。你看到的每一篇文章，仍然是一个可以随时用记事本打开的纯文本文件。

特意没变的东西

迁移里最容易出问题的其实是 URL。文章被搜索引擎或别人收藏之后，链接一旦变了，就等于把之前积累的访问一笔抹掉。所以这次我把所有旧链接原样保留：

  • 文章：仍然是 /posts/用 AI + CMD 整理电脑文件/ 这种带中文标题的形式
  • 页面：/about/、/archives/、/friends/、/search/ 一个都没动
  • 栏目：/gamedev/、/pixelart/、/talk/ 依然可以访问
  • 站点名、作者、头像、RSS 地址全部沿用旧站

文章正文也一字未改。只有三篇的正文里原来重复写了一遍标题（# 标题），渲染出来会跟页面标题打架，所以把重复的那一行去掉了；另外那篇 Markdown 语法笔记，小节标题从一级降成了二级，这样右侧目录才能正确显示层级。

新增的功能

  • 右侧目录：长文章自动生成，滚动时高亮当前小节
  • 相关文章：按标签和分类推荐，放在文章末尾
  • 归档页：按年份分组，一眼能看到写了多久
  • 分类与标签页：六个分类（技术 / 设计 / 阅读 / 像素画 / 游戏开发 / 杂谈）各有独立入口
  • 暗色模式：跟随系统，也可以手动切换
  • 阅读时间：列表和文章页都会显示

关于新增的那几篇文章

站内现在一共有 14 篇文章。除了原来的 5 篇（AI + CMD 整理文件、游戏续作感想、热情驱动的假象、Markdown 语法笔记、像素画岩石练习），还补了 9 篇：

  • 技术：用 Hugo 搭博客、为什么把笔记搬回纯文本、写给自己看的 Git 提交规范
  • 设计：留白不是空、一份克制的配色方案、字体选择的三个笨办法
  • 阅读：《瓦尔登湖》与低欲望的技术生活、年度书单、重读《禅与摩托车维修艺术》

写作方向没变，还是游戏开发、像素画、AI 和自己折腾过的工具，只是把攒在本地的一些笔记也一起放上来了。

顺带修掉的小问题

  • 构建用的 Hugo 换成了 extended 版本。Stack 用了 SCSS，普通版本编译不了，这个不改的话线上会直接构建失败。
  • 删掉了仓库里误提交的 hug22o.yaml（一份别人的 Stack 配置，里面还是别人的域名和标题）。
  • 文章的封面、分类图都是本地脚本生成的，不依赖图床，也不会有图片挂掉的问题。

接下来

评论系统这次仍然没有开，先把内容写起来更重要。游戏开发和像素画的记录会继续更新，也会把做过的小项目陆续整理出来。

完整的变更明细记在仓库根目录的 CHANGELOG.md 里，以后每次升级都会在那里留一条记录。
